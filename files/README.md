# Android APK dosyası

Bu klasöre **easy-PEDsy-3.1.apk** dosyasını yükleyin.

GitHub üzerinde klasöre girin → Add file → Upload files → APK dosyanızı seçin → Commit changes.

Dosyanın tam yolu: `files/easy-PEDsy-3.1.apk`

APK yüklendikten sonra `/downloads.html` sayfasındaki APK indir butonu otomatik görünür.
